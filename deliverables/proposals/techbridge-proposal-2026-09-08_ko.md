# 제안 개요

테크브릿지 고객지원 챗봇 플랫폼 구축 제안입니다. 현재 이메일/전화 중심의 CS 대응 구조를 AI 기반 1차 자동응대 체계로 전환하여, 평균 응답 시간을 6시간에서 3초 이내로 단축하고 성수기 문의 급증에도 안정적으로 대응할 수 있는 구조를 제안합니다. 예산 상한(3억원) 내에서 벤더 락인 없는 구조로 설계하였으며, 2027-03-01 가동을 목표로 합니다.

**승리 포인트**: (1) LLM 어댑터 패턴으로 특정 벤더에 종속되지 않는 유일한 제안, (2) 기존 Zendesk 계약을 그대로 활용해 추가 라이선스 비용 없이 연동, (3) 예산 상한 대비 총 비용 141.75백만원으로 약 53% 여유 확보.

# 고객 요구사항

| 구분 | 요구사항 |
|---|---|
| 기능 | 임베드형 챗봇 위젯, 주문/배송/반품 자동응대, 상담원 핸드오프, Zendesk 연동 |
| 비기능 | 응답 3초 이내, 개인정보 망분리 |
| 제약 | 예산 3억원, 2027-03-01 가동, 벤더 락인 지양 |

**미해결 질문**: 망분리 방식(물리적/논리적)은 요건 분석 단계에서 최우선 확정이 필요합니다.

# 제안 아키텍처

관리형 대화형 AI 플랫폼 + 시나리오 엔진 + LLM 어댑터 + Zendesk 연동 구조로 설계하였습니다. 사내 주문/배송 데이터는 VPC 내부에 유지하고, API 게이트웨이를 통한 논리적 망분리로 개인정보 요건을 충족합니다. 오케스트레이션 레이어는 오토스케일링 구성으로 성수기 3배 트래픽까지 대응 가능합니다.

# 문제 해결 방안

- **응답 지연 문제** → API 게이트웨이 캐싱 + 비동기 스트리밍 응답으로 3초 이내 목표 충족
- **벤더 락인 우려** → LLM 어댑터 패턴으로 엔진 교체 시 오케스트레이션 레이어 변경 불필요
- **기존 시스템 연동 부담** → Zendesk 공식 API/Webhook 활용, 커스텀 미들웨어 불필요
- **성수기 트래픽 급증** → 오토스케일링 구조로 평시 대비 3배까지 자동 확장
